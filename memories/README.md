# Hermes memory directory (template)

This directory holds Hermes' working memory files. Copy this directory structure to `~/.hermes/memories/`.

**This repo ships these files EMPTY on purpose** — the original contents are personal and confidential.

When Hermes runs, it maintains:

- `MEMORY.md` — compact high-signal notes injected into every session (environment facts, conventions, tool quirks)
- `USER.md` — who the user is: preferences, communication style, recurring corrections

Replace this template with your own as you use the agent. Hermes will prompt to save durable facts over time; keep them compact.
